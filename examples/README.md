# 示例

| 示例 | 场景 | 命令 |
|---|---|---|
| `quickstart.py` | 最小协作闭环：注册、自动分配、共享知识 | `python examples/quickstart.py` |
| `../scripts/seed_demo.py` | 五个角色的协作与意见冲突演示数据 | `python scripts/seed_demo.py` |

先按照 [快速开始](../docs/getting-started.md) 启动服务。所有示例默认请求
`http://127.0.0.1:8000`，可通过 `BLACKBOARD_BASE_URL` 或 `--base-url` 修改。
